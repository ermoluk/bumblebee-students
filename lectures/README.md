# 📚 Lectures

Beginner-friendly lecture materials for the Bumblebee course. Slides are in plain English, aimed at complete beginners, and branded with the FutureLab theme. All flying is done in the **Gazebo simulator** — no real drone needed.

| File | Topic |
| --- | --- |
| `Lecture1_FutureLab.pptx` | Pure Python from scratch — no drone (print, variables, types, `if/else`, `for`, functions) |
| `Lecture1_Python.ipynb` | Hands-on Jupyter notebook for Lecture 1 — run the examples and exercises yourself |
| `Lecture2_FutureLab.pptx` | First drone commands in Gazebo (`takeoff`, `move`, `hover`, `safe_land`, `try/finally`) |
| `Lecture3_FutureLab.pptx` | Waypoints, `for` loops, mission functions, ArUco markers (`fly_to`, `get_pos`, `set_aruco_map`) |

## How to use

1. Set up the simulator first: [Gazebo Setup (Windows)](https://github.com/futureLabKezad/bumblebee-students/wiki/Gazebo‐Setup‐(Windows)) / [Gazebo Setup (macOS)](https://github.com/futureLabKezad/bumblebee-students/wiki/Bumblebee‐Gazeba‐Setup‐(macOS)).
2. Follow the lectures in order; the notebook accompanies Lecture 1 (open it in Jupyter, VS Code, or view it right on GitHub).
3. After the lectures, move on to the assignments in [`../tasks/`](../tasks/) and the flight API reference: [Drone Py API](https://github.com/futureLabKezad/bumblebee-students/wiki/Drone‐Py‐API).
